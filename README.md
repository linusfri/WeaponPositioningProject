# Weapon positioning project

### What is this?
This is a mod which lets you position your weapon as you like, in depth and height. I think the weapons are too high up in vanilla and that they really obstruct your view.
So this is why i made this mod.

### To be aware of
I used quite a bit of Claude Opus 5.5 to make this, and i made in quite a short time. I have tested every part of it and reasoned about the code.
And as far as i can see it looks alright, and it also works as i want it to. So please, if you spot something bad practice or see something that could be improved, please open a PR or inform me about it.
